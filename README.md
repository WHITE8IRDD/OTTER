# Otter

A fast, reliable Android video downloader powered by the AV® engine.

## What's New in v1.1

- 100% first-attempt download success for all 5 supported platforms
- YouTube live stream downloads
- Silent auto-retry for transient network issues
- Honest 5-platform support list (YouTube, Facebook, Instagram, Twitter/X, TikTok)
- Friendly error messages with platform-specific guidance
- AV® engine branding
- Faster downloads via concurrent connection tiering
- 3-language support: English, Arabic (with RTL layout), French

## Supported Platforms

- YouTube (videos, Shorts, live streams)
- Facebook (posts, fb.watch, watch.facebook.com)
- Instagram (Reels, image carousels, posts)
- Twitter / X (video tweets from x.com and twitter.com)
- TikTok (standard and short URLs)

## Features

- Download videos from 5 popular platforms
- Pause, resume, and stop downloads
- Share sheet integration for quick downloads
- Subtitle and audio track selection
- Cookie-based authentication
- 3-language support (English, Arabic, French)
- Customizable download location
- Dark mode with multiple accent colors
- Powered by AV® engine for ultra-fast media extraction
